TerrainForge 0.3.8 — исправление для 0.3.7

В колесе Q появился отдельный режим «Копировать/вставить». Прямоугольник отмечает A/B клавишей «Применить», Линия — два конца, Многоугольник — вершины (двойное нажатие после 3+ точек), Круг/Квадрат копирует область кисти. HUD показывает следующий шаг. Снег теперь находится в «Покраска» > DeepSnow (удерживайте Shift, чтобы убрать). F5 блокирует локальное движение и камеру; Esc приостанавливает весь мир в одиночной игре. 0.3.6: вкладки F5 расположены в два ряда, а настройки соответствуют выбранной операции. У Ramp есть режимы «Две точки», «Фиксированный угол» и «Непрерывная трасса»; круговые рампы запланированы для 0.4.0.

📥 Установка

Требования

  • BepInEx 5 (x64, Mono) на клиенте и сервере. У пользователей Thunderstore он уже есть.

Шаги

  1. Скачайте TerrainForge-<version>.zip с Thunderstore или GitHub Releases.
  2. Распакуйте и поместите TerrainForge.dll в: - Клиент: ...\BepInEx\plugins\TerrainForge\TerrainForge.dll - Сервер: <сервер>\BepInEx\plugins\TerrainForge\TerrainForge.dll
  3. Перезапустите игру / сервер.

⚠️ Требуется установка на клиенте И сервере для правок больше ±8 м и корректной репликации.

🚀 Быстрый старт

  1. Зайдите в мир. Жезл TerrainForge (клон молота) выдаётся и экипируется автоматически.
  2. Нажмите F5, чтобы открыть меню (или кликните кнопку TerrainForge в меню паузы ESC).
  3. Экипируйте жезл, если он не экипирован.
  4. Наведитесь на местность и удерживайте правую кнопку мыши (Mouse1) для лепки.
  5. Используйте , для переключения операций, . для форм, / для красок.
  6. Удерживайте Q → радиальное меню, отпустите для подтверждения.
  7. Ctrl+Z / Ctrl+Y для отмены/повтора.

🔄 Операции

Операция Описание
Выровнять Выравнивает до указанной высоты (Shift = на уровне ваших ног). Фиксированная высота через Пипетку (G) или текстовое поле в НАСТРОЙКАХ.
Поднять Поднимает местность на RaiseDelta за применение. Режим затухания задаёт форму.
Опустить Опускает местность на RaiseDelta за применение. Режим затухания задаёт форму.
Сгладить Настоящее размытие: усредняет каждую вершину с её 8 соседями. Удерживайте для постепенного эффекта. Режимы: Полный (оба), только гребни (понижает), только впадины (повышает). Форма Линия = сглаживание пути.
Пандус 3 режима (переключение H):
• Две точки: отметьте A и B → прямая наклонная плоскость соединяет высоты.
• Фиксированный угол: B = направление/длина; высота = SlopeAngle (вверх/вниз в зависимости от прицела). Регулировка через Alt+радиус.
• Путь: отметьте кривую A→B→C… (двойное нажатие при 3+ закрывает) → плавный Catmull-Rom.
Ширина = радиус кисти. Мягкость = смешивание только по боковым краям. Предпросмотр: заполненный коридор + кольца высот у A/B.
Берег Выравнивает к уровню воды + отступ ShoreOffset (пляжи). Мягкость как у Выровнять.
Рисовать Типы: Dirt, Cultivated, Paved, ClearVegetation, DeepSnow, Reset. Регулируемая сила.
Восстановить Возвращает местность в исходное состояние (высота + краска).
Копировать/вставить Отдельный режим колеса Q для выбора участка земли и размещения штампов.

⚙️ Режимы затухания (Поднять/Опустить)

Настройка в НАСТРОЙКАХ → "Затухание Raise/Lower":

🧱 Штампы (Копировать/Вставить)

Мощная функция для копирования структур местности.

Выделение прямоугольником (рекомендуется)

Выберите «Копировать/вставить» в колесе Q. Клавиша «Применить» задаёт область: два угла прямоугольника, два конца линии, вершины многоугольника (двойное нажатие после 3+ точек) или область кисти для круга/квадрата. HUD подсказывает следующий шаг.

Рабочий процесс

  1. Отметьте область: используйте любую форму (Круг, Прямоугольник, Линия, Полигон, Пандус) — или выделение прямоугольником выше.
  2. Копировать: Ctrl+Shift+C → "Штамп скопирован: X плиток" (буфер в ОЗУ).
  3. Предпросмотр вставки: Ctrl+Shift+V → призрачный каркас на прицеле. - Q/E = поворот ±15° - Alt+Колесо = непрерывный поворот - Shift+Колесо = масштаб 0.25×–4× - Esc = отмена
  4. Confirm: Нажмите клавишу вставки ещё раз, чтобы подтвердить предпросмотр.

Штампы выделения записывают только внутри скопированной области; местность снаружи остаётся нетронутой.

История

  • До 10 штампов в ОЗУ (сначала самые новые).
  • Клавиши Следующий штамп / Предыдущий штамп (переназначаемые) перебирают их.
  • Вспышка: "История штампов: Copy: 3 плитки [2/5]"

Хранение

  • НАСТРОЙКИ → ШТАМПЫ:
  • Сохранить текущий штамп на диск (.stamp в BepInEx/config/TerrainForge/stamps/, макс. 12).
  • Загрузить штамп в буфер обмена.
  • Список/удаление сохранённых штампов.

Инструмент штампа

  • НАСТРОЙКИ → "Инструмент штампа" (4 варианта):
  • Same as brush (по умолчанию) — использует тот же инструмент, что и кисть
  • Any — без требований
  • Pickaxe — требуется экипированная кирка
  • TerrainForge Rod — требуется жезл мода
  • HUD показывает STAMP READY [2/5], когда инструмент экипирован + есть штампы в буфере.
  • Без инструмента: Stamp: tool not equipped, копирование/вставка заблокированы.

💾 Снимки (Резервные копии)

Полное резервное копирование/восстановление местности.

Сохранить

  1. НАСТРОЙКИ → СНИМКИ.
  2. Имя (пусто = авто дата/время).
  3. Сохранить → правленые плитки в BepInEx/config/TerrainForge/snapshots/<имя>.dat (макс. 12).

Загрузить

  1. Выберите снимок.
  2. Загрузить → восстанавливает плитки с правами владения, 1 шаг отмены.
  3. Незагруженные плитки корректно предупреждают — импортируйте рядом с исходным местоположением.

Возможности

  • Версионированный бинарный формат (.dat).
  • Восстанавливает высоту + сглаживание + краску + права владения.
  • Импорт можно отменить (Ctrl+Z откатывает импорт).
  • Незагруженные плитки корректно предупреждают.

💾 Профили

Сохранение/загрузка полных конфигураций кисти.

  • НАСТРОЙКИ → ПРОФИЛИ.
  • Имя + Сохранить → радиус, мягкость, операция, форма, краска, режим пандуса, угол, режим сглаживания, дельта подъёма, сила краски, затухание, смещение берега.
  • Загрузить → применяется мгновенно.
  • Макс. 12 профилей (формат, независимый от культуры, в Presets > Slots).
  • Привязка клавиш: Next Profile (назначьте в КЛАВИШАХ) для переключения.

🌍 Мультиплеер

Требования

  • Мод на клиенте И сервере для правок больше ±8 м и корректной репликации.
  • UnlockDeltaLimit также на сервере, иначе сервер ограничивает местность.

Авторитет сервера (синхронизация конфигурации)

Когда сервер использует мод, его секция Server имеет приоритет: - AllowTerrainEdits (по умолчанию true) — главный переключатель; если false, клиенты не могут применять/отменять/повторять. - AdminOnlyEdits (по умолчанию false) — редактировать могут только админы/хост. - RespectWards (по умолчанию true) — блокирует правки внутри чужих вардов. - RadiusCap / DeltaCap (0 = выкл.) — ограничения, применяемые сервером, видны в HUD+предпросмотре.

Серверы без мода игнорируют секцию → клиент работает для тестирования.

Предотвращение рассинхронизации

  • Держите MaxUpDelta / MaxDownDelta согласованными на сервере + клиентах.
  • Большие радиусы могут рассинхронизировать клиентов без мода.

🐛 Решение проблем

Проблема Решение
Меню не появляется / невидимый курсор Закройте игру. Удалите %APPDATA%\Thunderstore Mod Manager\DataFolder\Valheim\profiles\ВашПрофиль\BepInEx\plugins\TerrainForge\ и %APPDATA%\Thunderstore Mod Manager\PackageCache\. Перезапустите TMM, проверьте обновления.
Обновление не отображается в TMM TMM → Settings → "Refresh mod list" (Ctrl+R). Закройте/откройте TMM. Проверьте правильный профиль.
Конфликт версий в Thunderstore Поднимите версию (0.3.3 → 0.3.4) в .csproj, Plugin.cs, manifest.json. Пересоберите + перезагрузите.
Копирование/вставка штампа ничего не делает HUD: STAMP READY [X/Y] = готово. Если "инструмент не экипирован", экипируйте инструмент (НАСТРОЙКИ → Инструмент штампа).
Предпросмотр невидим под водой Исправлено в 0.3.2 — предпросмотр плавает на поверхности. Обновитесь.
Круги на Линии/Прямоугольнике/Полигоне Исправлено в 0.3.2 — показывается только отмеченный контур. Обновитесь.
Радиальное колесо не работает Исправлено в 0.3.2 (ZInput.GetMouseScrollWheel()) и 0.3.4 (выделение больше не стирается при центрированном курсоре). Обновитесь.
Конфигурация не сохраняется Закройте меню (F5) для автосохранения. Или отредактируйте BepInEx/config/com.terrainforge.valheim.cfg напрямую.
