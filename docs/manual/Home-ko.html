TerrainForge 0.3.8 — 0.3.7 핫픽스

Q 휠에 전용 복사/붙여넣기 모드가 추가되었습니다. 사각형은 적용으로 A/B, 선은 양 끝점, 다각형은 꼭짓점을 지정하고 3개 이상에서 두 번 눌러 복사하며, 원/정사각형은 브러시 범위를 복사합니다. HUD가 다음 단계를 안내합니다. 눈은 페인트 > DeepSnow에 통합되었습니다(Shift를 누르면 제거). F5에서는 로컬 이동과 카메라가 고정되며, Esc는 싱글 플레이 세계 전체를 일시 정지합니다. 0.3.6: F5 탭을 두 줄로 정리하고 선택한 작업에 필요한 설정만 표시합니다. Ramp에는 두 점, 고정 각도, 연결 경로 모드가 있으며 원형 램프는 0.4.0 계획에 포함되었습니다.

📥 설치

요구 사항

  • BepInEx 5 (x64, Mono) — 클라이언트와 서버 모두. Thunderstore 사용자는 이미 설치되어 있습니다.

단계

  1. Thunderstore 또는 GitHub Releases에서 TerrainForge-<version>.zip을 다운로드합니다.
  2. 압축을 풀고 TerrainForge.dll을 다음 위치에 놓습니다: - 클라이언트: ...\BepInEx\plugins\TerrainForge\TerrainForge.dll - 서버: <server>\BepInEx\plugins\TerrainForge\TerrainForge.dll
  3. 게임 / 서버를 재시작합니다.

⚠️ ±8 m를 초과하는 편집과 올바른 복제를 위해서는 클라이언트와 서버 모두에 설치해야 합니다.

🚀 빠른 시작

  1. 월드에 접속합니다. TerrainForge 막대기(망치 복제품)가 자동으로 지급되고 장착됩니다.
  2. F5를 눌러 메뉴를 엽니다 (ESC 일시정지 메뉴의 TerrainForge 버튼을 클릭해도 됩니다).
  3. 막대기가 장착되어 있지 않다면 장착합니다.
  4. 지형을 조준하고 오른쪽 클릭(Mouse1)을 길게 눌러 조형합니다.
  5. ,로 작업을, .로 모양을, /로 페인트를 순환합니다.
  6. Q를 길게 누르면 → 방사형 메뉴가 열리고, 놓으면 확정됩니다.
  7. Ctrl+Z / Ctrl+Y로 실행 취소/다시 실행합니다.

🔄 작업

작업 설명
평탄화 조준한 높이로 평탄화합니다 (Shift = 발 위치). 스포이트(G) 또는 SETTINGS 텍스트박스로 고정 높이를 지정합니다.
올리기 적용할 때마다 지형을 RaiseDelta만큼 올립니다. 감쇠 모드가 형태를 결정합니다.
내리기 적용할 때마다 지형을 RaiseDelta만큼 내립니다. 감쇠 모드가 형태를 결정합니다.
부드럽게 실제 블러: 각 정점을 8개 이웃과 평균냅니다. 길게 누르면 점진적으로 적용됩니다. 모드: 전체(양쪽), 능선만(내림), 움푹한 곳만(올림). 선 모양 = 경로를 스무딩합니다.
램프 3가지 모드 (H 순환):
• 두 점: A와 B를 표시 → 직선 경사가 높이를 연결합니다.
• 고정 각도: B = 방향/길이; 높이 = SlopeAngle (크로스헤어에 따라 위/아래). Alt+반경으로 조정합니다.
• 경로: 곡선 A→B→C… 를 표시 (3개 이상에서 두 번 누르면 닫힘) → 부드러운 Catmull-Rom.
너비 = 브러시 반경. 부드러움 = 측면 가장자리에서만 블렌드. 미리보기: 채워진 회랑 + A/B의 높이 링.
해안 수면 높이 + ShoreOffset 여백을 향해 평탄화합니다 (해변). 부드러움은 평탄화와 동일합니다.
페인트 유형: Dirt, Cultivated, Paved, ClearVegetation, DeepSnow, Reset. 강도 조절 가능.
복원 지형을 원래 상태로 되돌립니다 (높이 + 페인트).
복사/붙여넣기 지형을 선택하고 스탬프를 놓는 Q 휠 전용 모드입니다.

🧱 스탬프 (복사/붙여넣기)

지형 구조를 복제하는 강력한 기능입니다.

사각형 선택 (권장)

Q 휠에서 복사/붙여넣기를 선택하세요. 적용을 눌러 영역을 지정합니다. 사각형은 두 모서리, 선은 양 끝점, 다각형은 꼭짓점(3개 이상에서 두 번 누름), 원/정사각형은 현재 브러시 범위를 사용합니다. HUD가 다음 단계를 표시합니다.

워크플로

  1. 영역 표시: 아무 모양이나 사용합니다 (원, Rect, 선, 다각형, 램프) — 또는 위의 사각형 선택.
  2. 복사: Ctrl+Shift+C → "스탬프 복사됨: X tiles" (RAM 클립보드).
  3. 붙여넣기 미리보기: Ctrl+Shift+V → 크로스헤어에 고스트 와이어프레임. - Q/E = ±15° 회전 - Alt+휠 = 연속 회전 - Shift+휠 = 0.25×–4× 크기 조절 - Esc = 취소
  4. 확정: 붙여넣기 키를 다시 누르면 미리보기를 확정합니다.

선택 스탬프는 복사한 영역 내부에만 기록합니다; 그 밖의 지형은 손대지 않습니다.

기록

  • RAM에 최대 10개 스탬프 (최근 순).
  • 다음 스탬프 / 이전 스탬프 키(재지정 가능)로 순환합니다.
  • 플래시: "스탬프 기록: Copy: 3 tiles [2/5]"

영속성

  • SETTINGS → STAMPS:
  • 현재 스탬프를 디스크에 저장합니다 (BepInEx/config/TerrainForge/stamps/의 .stamp, 최대 12개).
  • 스탬프를 클립보드로 불러옵니다.
  • 저장된 스탬프를 나열/삭제합니다.

스탬프 도구

  • SETTINGS → "Stamp tool" (4가지 옵션):
  • Same as brush (기본값) — 브러시와 동일한 도구를 사용합니다
  • Any — 요구 사항 없음
  • Pickaxe — 곡괭이 장착 필요
  • TerrainForge Rod — 모드의 막대기 필요
  • 도구가 장착되어 있고 클립보드에 스탬프가 있으면 HUD가 STAMP READY [2/5]를 표시합니다.
  • 도구가 없으면: Stamp: tool not equipped, 복사/붙여넣기가 차단됩니다.

💾 스냅샷 (백업)

전체 지형 백업/복원.

저장

  1. SETTINGS → SNAPSHOTS.
  2. 이름 (비우면 자동 날짜/시간).
  3. Save → 편집한 타일을 BepInEx/config/TerrainForge/snapshots/<name>.dat에 저장합니다 (최대 12개).

불러오기

  1. 스냅샷을 선택합니다.
  2. Load → 소유권과 함께 타일을 복원합니다, 1 실행 취소 단계.
  3. 로드되지 않은 타일은 깔끔하게 경고합니다 — 원래 위치 근처에서 가져오세요.

기능

  • 버전이 관리되는 이진 형식 (.dat).
  • 높이 + smooth + 페인트 + 소유권을 복원합니다.
  • 가져오기는 실행 취소할 수 있습니다 (Ctrl+Z로 가져오기를 되돌립니다).
  • 로드되지 않은 타일은 깔끔하게 경고합니다.

💾 프로필

완전한 브러시 구성을 저장/불러옵니다.

  • SETTINGS → PROFILES.
  • 이름 + Save → 반경, 부드러움, 작업, 모양, 페인트, 램프 모드, 각도, 스무딩 모드, 올리기 델타, 페인트 강도, 감쇠, 해안 오프셋.
  • Load → 즉시 적용됩니다.
  • 최대 12개 프로필 (Presets > Slots의 culture-invariant 형식).
  • 키 바인딩: Next Profile (KEYS에서 지정) 로 순환합니다.

🌍 멀티플레이어

요구 사항

  • ±8 m를 초과하는 편집과 올바른 복제를 위해서는 클라이언트와 서버 모두에 모드가 필요합니다.
  • 서버에도 UnlockDeltaLimit를 설정해야 합니다, 그렇지 않으면 서버가 지형을 제한합니다.

서버 권한 (Config Sync)

서버가 모드를 실행하면 서버의 Server 섹션이 우선합니다: - AllowTerrainEdits (기본값 true) — 마스터 스위치; false이면 클라이언트는 적용/실행 취소/다시 실행할 수 없습니다. - AdminOnlyEdits (기본값 false) — 관리자/호스트만 편집할 수 있습니다. - RespectWards (기본값 true) — 다른 사람의 ward 내부 편집을 차단합니다. - RadiusCap / DeltaCap (0 = off) — 서버가 강제하는 상한, HUD+미리보기에 표시됩니다.

모드가 없는 서버는 이 섹션을 무시합니다 → 클라이언트는 테스트용으로 작동합니다.

디싱크 방지

  • 서버 + 클라이언트에서 MaxUpDelta / MaxDownDelta를 일관되게 유지하세요.
  • 큰 반경은 모드가 없는 클라이언트를 디싱크시킬 수 있습니다.

🐛 문제 해결

문제 해결 방법
메뉴가 나타나지 않음 / 커서가 보이지 않음 게임을 종료합니다. %APPDATA%\Thunderstore Mod Manager\DataFolder\Valheim\profiles\YourProfile\BepInEx\plugins\TerrainForge\ 및 %APPDATA%\Thunderstore Mod Manager\PackageCache\를 삭제합니다. TMM을 재시작하고 업데이트를 확인합니다.
TMM에 업데이트가 표시되지 않음 TMM → Settings → "Refresh mod list" (Ctrl+R). TMM을 닫았다 다시 엽니다. 올바른 프로필인지 확인합니다.
Thunderstore 버전 충돌 .csproj, Plugin.cs, manifest.json에서 버전을 올립니다 (0.3.3 → 0.3.4). 다시 빌드 + 다시 업로드합니다.
스탬프 복사/붙여넣기가 아무것도 하지 않음 HUD: STAMP READY [X/Y] = 준비됨. "tool not equipped"라고 나오면 도구를 장착합니다 (SETTINGS → Stamp tool).
물속에서 미리보기가 보이지 않음 0.3.2에서 수정됨 — 미리보기가 수면에 떠 있습니다. 업데이트하세요.
선/Rect/Poly에 원이 표시됨 0.3.2에서 수정됨 — 표시한 윤곽만 표시됩니다. 업데이트하세요.
방사형 휠이 작동하지 않음 0.3.2 (ZInput.GetMouseScrollWheel()) 및 0.3.4 (커서가 중앙에 있어도 선택이 더 이상 지워지지 않음)에서 수정됨. 업데이트하세요.
Config가 저장되지 않음 메뉴를 닫으면(F5) 자동 저장됩니다. 또는 BepInEx/config/com.terrainforge.valheim.cfg를 직접 편집합니다.
멀티플레이어 디싱크 클라이언트+서버에 모드. 둘 다 UnlockDeltaLimit. 동일한 MaxUpDelta/MaxDownDelta.
빌드 실패 .csproj의 ValheimDir, BepInExCoreDir 경로를 확인하거나 CLI로 확인합니다. .NET SDK 8+가 필요합니다.
컴파일 / 패키징 dotnet build -c Release (build/의 DLL), -p:Deploy=true (프로필에 설치) 또는 -p:Package=true (build/의 zip).
