TerrainForge 0.3.8 — виправлення для 0.3.7

У колесі Q є окремий режим «Копіювати/Вставити». Прямокутник позначає A/B клавішею «Застосувати», Лінія — два кінці; Багатокутник додає вершини й копіює подвійним натисканням після 3+ точок; Коло/Квадрат копіює область пензля. HUD показує наступний крок. Сніг у Фарбуванні > DeepSnow (утримуйте Shift, щоб прибрати). F5 блокує локальний рух і камеру; Esc призупиняє весь світ в одиночній грі. 0.3.6: вкладки F5 розміщено у два ряди, а параметри залежать від вибраної операції. Ramp має режими «Дві точки», «Фіксований кут» і «Безперервна траса»; кругові рампи заплановано для 0.4.0.

📥 Встановлення

Вимоги

  • BepInEx 5 (x64, Mono) на клієнті та сервері. У користувачів Thunderstore він уже є.

Кроки

  1. Завантажте TerrainForge-<version>.zip з Thunderstore або GitHub Releases.
  2. Розпакуйте та розмістіть TerrainForge.dll у: - Клієнт: ...\BepInEx\plugins\TerrainForge\TerrainForge.dll - Сервер: <server>\BepInEx\plugins\TerrainForge\TerrainForge.dll
  3. Перезапустіть гру / сервер.

⚠️ Потрібно встановити і на клієнті, І на сервері для редагування понад ±8 m та правильної реплікації.

🚀 Швидкий старт

  1. Приєднайтеся до світу. Жезл TerrainForge (клон молота) видається та екіпірується автоматично.
  2. Натисніть F5, щоб відкрити меню (або натисніть кнопку TerrainForge в меню паузи ESC).
  3. Екіпіруйте жезл, якщо він не екіпірований.
  4. Наведіться на місцевість і утримуйте праву кнопку миші (Mouse1), щоб ліпити.
  5. Використовуйте , для перемикання операцій, . для форм, / для фарб.
  6. Утримуйте Q → радіальне меню, відпустіть для підтвердження.
  7. Ctrl+Z / Ctrl+Y для скасування/повторення.

🔄 Операції

Операція Опис
Вирівняти Вирівнює до вказаної висоти (Shift = на рівні ваших ніг). Фіксована висота через піпетку (G) або текстове поле в НАЛАШТУВАННЯХ.
Підняти Піднімає місцевість на RaiseDelta за одне застосування. Режим затухання визначає форму.
Опустити Опускає місцевість на RaiseDelta за одне застосування. Режим затухання визначає форму.
Згладити Справжнє розмиття: усереднює кожну вершину з її 8 сусідами. Утримуйте для поступової дії. Режими: Повний (обидва), Лише гребені (опускає), Лише западини (піднімає). Форма Лінія = згладити шлях.
Рампа 3 режими (перемикання H):
• Дві точки: позначте A і B → пряма рампа з'єднує висоти.
• Фіксований кут: B = напрямок/довжина; висота = SlopeAngle (вгору/вниз відповідно до прицілу). Регулюйте Alt+радіус.
• Шлях: позначте криву A→B→C… (подвійне натискання з 3+ закриває) → плавна Catmull-Rom.
Ширина = радіус пензля. М'якість = змішування лише на бокових краях. Перегляд: заповнений коридор + кільця висоти в A/B.
Берег Вирівнює до рівня води + відступ ShoreOffset (пляжі). М'якість як у Вирівнювання.
Фарбувати Типи: Dirt, Cultivated, Paved, ClearVegetation, DeepSnow, Reset. Регульована сила.
Відновити Повертає місцевість до початкового стану (висота + фарба).
Копіювати/Вставити Окремий режим колеса Q для вибору ділянки та розміщення stamp.

🧱 Штампи (Копіювати/Вставити)

Потужна функція для копіювання структур місцевості.

Вибір прямокутником (рекомендовано)

Виберіть «Копіювати/Вставити» в колесі Q. «Застосувати» позначає область: два кути для Прямокутника, два кінці для Лінії, вершини для Багатокутника (подвійне натискання після 3+ точок) або область пензля для Кола/Квадрата. HUD підказує наступний крок.

Робочий процес

  1. Позначте область: використайте будь-яку форму (Коло, Прямокутник, Лінія, Полігон, Рампа) — або вибір прямокутником вище.
  2. Копіювати: Ctrl+Shift+C → "Stamp скопійовано: X tiles" (буфер обміну в RAM).
  3. Перегляд вставки: Ctrl+Shift+V → примарний каркас на прицілі. - Q/E = обертання ±15° - Alt+Колесо = безперервне обертання - Shift+Колесо = масштаб 0.25×–4× - Esc = скасувати
  4. Підтвердити: натисніть клавішу вставлення ще раз, щоб підтвердити перегляд.

Штампи виділення записують лише всередині скопійованої області; місцевість поза нею залишається недоторканою.

Історія

  • До 10 штампів у RAM (найновіші першими).
  • Клавіші Next stamp / Previous stamp (можна перепризначити) перемикають їх.
  • Спалах: "Історія штампів: Copy: 3 tiles [2/5]"

Збереження

  • НАЛАШТУВАННЯ → STAMPS:
  • Зберегти поточний штамп на диск (.stamp у BepInEx/config/TerrainForge/stamps/, макс 12).
  • Завантажити штамп у буфер обміну.
  • Перелічити/видалити збережені штампи.

Інструмент штампів

  • НАЛАШТУВАННЯ → "Інструмент штампів" (4 опції):
  • Так само, як пензель (типово) — використовує той самий інструмент, що й пензель
  • Будь-який — без вимог
  • Кирка — потрібна екіпірована кирка
  • Жезл TerrainForge — потрібен жезл мода
  • HUD показує STAMP READY [2/5], коли інструмент екіпіровано + є штампи в буфері обміну.
  • Без інструмента: Stamp: tool not equipped, копіювання/вставлення заблоковано.

💾 Знімки (Резервні копії)

Повне резервне копіювання/відновлення місцевості.

Зберегти

  1. НАЛАШТУВАННЯ → SNAPSHOTS.
  2. Назва (порожня = авто дата/час).
  3. Зберегти → відредаговані плити в BepInEx/config/TerrainForge/snapshots/<name>.dat (макс 12).

Завантажити

  1. Виберіть знімок.
  2. Завантажити → відновлює плити з власністю, 1 крок скасування.
  3. Незавантажені плити попереджають коректно — імпортуйте близько до оригінального місця.

Можливості

  • Версіонований бінарний формат (.dat).
  • Відновлює висоту + згладжування + фарбу + власність.
  • Імпорт можна скасувати (Ctrl+Z відкочує імпорт).
  • Незавантажені плити попереджають коректно.

💾 Профілі

Зберігайте/завантажуйте повні конфігурації пензля.

  • НАЛАШТУВАННЯ → PROFILES.
  • Назва + Зберегти → радіус, м'якість, операція, форма, фарба, режим рампи, кут, режим згладжування, raise delta, сила фарби, затухання, відступ берега.
  • Завантажити → застосовується миттєво.
  • Макс 12 профілів (культуро-незалежний формат у Presets > Slots).
  • Клавіша: Next Profile (призначте в КЛАВІШАХ) для перемикання.

🌍 Мультиплеєр

Вимоги

  • Мод на клієнті ТА сервері для редагування понад ±8 m та правильної реплікації.
  • UnlockDeltaLimit також на сервері, інакше сервер обмежує місцевість.

Серверний авторитет (Синхронізація конфігу)

Коли сервер запускає мод, його розділ Server має перевагу: - AllowTerrainEdits (типово true) — головний перемикач; якщо false, клієнти не можуть застосовувати/скасовувати/повторювати. - AdminOnlyEdits (типово false) — лише адміністратори/хост можуть редагувати. - RespectWards (типово true) — блокує редагування всередині чужих ward. - RadiusCap / DeltaCap (0 = вимк) — обмеження, що застосовує сервер, видимі в HUD+перегляді.

Сервери без мода ігнорують цей розділ → клієнт працює для тестування.

Запобігання десинхронізації

  • Тримайте MaxUpDelta / MaxDownDelta узгодженими на сервері + клієнтах.
  • Великі радіуси можуть десинхронізувати клієнтів без мода.

Меню не з'являється / невидимий курсор Закрийте гру. Видаліть %APPDATA%\Thunderstore Mod Manager\DataFolder\Valheim\profiles\YourProfile\BepInEx\plugins\TerrainForge\ та %APPDATA%\Thunderstore Mod Manager\PackageCache\. Перезапустіть TMM, перевірте оновлення.
Оновлення не з'являється в TMM TMM → Settings → "Refresh mod list" (Ctrl+R). Закрийте/відкрийте TMM. Перевірте правильний профіль.
Конфлікт версій у Thunderstore Підніміть версію (0.3.3 → 0.3.4) у .csproj, Plugin.cs, manifest.json. Перебудуйте + перезавантажте.
Копіювання/вставлення штампу нічого не робить HUD: STAMP READY [X/Y] = готово. Якщо "tool not equipped", екіпіруйте інструмент (НАЛАШТУВАННЯ → Інструмент штампів).
Перегляд невидимий під водою Виправлено в 0.3.2 — перегляд плаває на поверхні. Оновіться.
Кола на Лінії/Прямокутнику/Полігоні Виправлено в 0.3.2 — показується лише позначений контур. Оновіться.
Радіальне колесо не працює Виправлено в 0.3.2 (ZInput.GetMouseScrollWheel()) та 0.3.4 (виділення більше не стирається при центрованому курсорі). Оновіться.
Конфіг не зберігається Закрийте меню (F5) для автозбереження. Або редагуйте BepInEx/config/com.terrainforge.valheim.cfg напряму.
Десинхронізація в мультиплеєрі Мод на клієнті+сервері. UnlockDeltaLimit на обох. Однакові MaxUpDelta/MaxDownDelta.
Збірка не вдається Перевірте шляхи ValheimDir, BepInExCoreDir у .csproj або через CLI. Потрібен .NET SDK 8+.
Компіляція / пакування dotnet build -c Release (DLL у build/), -p:Deploy=true (встановлює у профіль) або -p:Package=true (zip у build/).
