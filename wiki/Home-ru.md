## 📥 Установка

[Overview](Overview) · ### Требования
- **BepInEx 5** (x64, Mono) на клиенте и сервере. У пользователей Thunderstore он уже есть.
- **Jotunn** (`ValheimModding-Jotunn`) — регистрирует пользовательский инструмент. Указан в `manifest.json`; Thunderstore устанавливает его автоматически.

### Шаги
1. Скачайте `TerrainForge-<version>.zip` с Thunderstore или GitHub Releases.
2. Распакуйте и поместите `TerrainForge.dll` в:
   - **Клиент:** `...\BepInEx\plugins\TerrainForge\TerrainForge.dll`
   - **Сервер:** `<сервер>\BepInEx\plugins\TerrainForge\TerrainForge.dll`
3. Перезапустите игру / сервер.

> ⚠️ **Требуется установка на клиенте И сервере** для правок больше ±8 м и корректной репликации.

## 🚀 Быстрый старт

[Overview](Overview) · 1. Зайдите в мир. **Жезл TerrainForge** (клон молота) выдаётся и экипируется автоматически.
2. Нажмите `F5`, чтобы открыть меню (или кликните кнопку **TerrainForge** в меню паузы `ESC`).
3. Экипируйте жезл, если он не экипирован.
4. Наведитесь на местность и удерживайте **правую кнопку мыши** (`Mouse1`) для лепки.
5. Используйте `,` для переключения операций, `.` для форм, `/` для красок.
6. Удерживайте `Q` → радиальное меню, отпустите для подтверждения.
7. `Ctrl+Z` / `Ctrl+Y` для отмены/повтора.

## ⌨️ Управление

[Overview](Overview) · | Действие | Клавиша по умолчанию | Описание |
|--------|-------------|-------------|
| Применить кисть | Удерживать `Mouse1` (правая кнопка) | Лепит местность под прицелом |
| Радиус + | `=` или `Ctrl`+Колесо | Увеличивает радиус кисти |
| Радиус − | `-` или `Ctrl`+Колесо | Уменьшает радиус кисти |
| Переключить операцию | `,` | Перебирает 9 операций |
| Переключить форму | `.` | Круг → Квадрат → Линия → Прямоугольник → Полигон |
| Переключить краску | `/` | Перебирает 6 типов краски |
| Выравнивание по ногам | Удерживать `Left Shift` | Выровнять использует высоту игрока |
| Отмена | `Ctrl+Z` | Отменяет последний штрих |
| Повтор | `Ctrl+Y` | Повторяет отменённый штрих |
| Пипетка | `G` | Фиксирует высоту Выровнять на прицеле (повторно = снять) |
| Режим пандуса | `H` | Перебирает: Две точки → Фиксированный угол → Путь (или выберите 3 кнопками в НАСТРОЙКАХ) |
| Угол фиксированного пандуса | Удерживать `Alt` + радиус/колесо | Регулирует угол в фиксированном режиме |
| Радиальное меню | Удерживать `Q` | Выберите операцию мышью, отпустите для подтверждения |
| Режим настройки | `V` | Колесо = радиус, замораживает зум/панель/карту |
| Точная настройка (0.1 м) | Удерживать `Shift` + колесо/радиус | Точная регулировка радиуса |
| **Копировать штамп** | `Ctrl+Shift+C` | Копирует отмеченную область в буфер обмена |
| **Вставить штамп** | `Ctrl+Shift+V` | Призрачный предпросмотр, клик подтверждает |
| Получить жезл | `F8` | Выдаёт жезл TerrainForge |
| Открыть меню | `F5` | Открывает меню клавиш/справки/настроек |

**Дополнительные клавиши (без значения по умолчанию, назначьте их в КЛАВИШАХ):**
- Прямая операция: Выровнять, Поднять, Опустить, Сгладить, Рисовать, Восстановить, Пандус, Берег, Снег
- Следующий / предыдущий профиль
- Следующий / предыдущий штамп (история)

**Раздел «Быстрые действия» (вкладка КЛАВИШИ):** кнопки для функций без обязательного сочетания — Отмена, Повтор, Зафиксировать высоту, Копировать/Вставить штамп, Предыдущий штамп, Очистить метки, тепловые карты и Диагностика материала (выводит шейдер + слоты текстур в лог).

## 🔄 Операции

[Overview](Overview) · | Операция | Описание |
|-----------|-------------|
| **Выровнять** | Выравнивает до указанной высоты (Shift = на уровне ваших ног). Фиксированная высота через Пипетку (`G`) или текстовое поле в НАСТРОЙКАХ. |
| **Поднять** | Поднимает местность на `RaiseDelta` за применение. Режим затухания задаёт форму. |
| **Опустить** | Опускает местность на `RaiseDelta` за применение. Режим затухания задаёт форму. |
| **Сгладить** | Настоящее размытие: усредняет каждую вершину с её 8 соседями. Удерживайте для постепенного эффекта. **Режимы:** Полный (оба), только гребни (понижает), только впадины (повышает). Форма Линия = сглаживание пути. |
| **Пандус** | **3 режима** (переключение `H`):<br>• **Две точки**: отметьте A и B → прямая наклонная плоскость соединяет высоты.<br>• **Фиксированный угол**: B = направление/длина; высота = `SlopeAngle` (вверх/вниз в зависимости от прицела). Регулировка через `Alt`+радиус.<br>• **Путь**: отметьте кривую A→B→C… (двойное нажатие при 3+ закрывает) → плавный Catmull-Rom.<br>Ширина = радиус кисти. Мягкость = смешивание только по боковым краям. Предпросмотр: заполненный коридор + кольца высот у A/B. |
| **Берег** | Выравнивает к уровню воды + отступ `ShoreOffset` (пляжи). Мягкость как у Выровнять. |
| **Рисовать** | Типы: Dirt, Cultivated, Paved, ClearVegetation, DeepSnow, Reset. Регулируемая сила. |
| **Восстановить** | Возвращает местность в исходное состояние (высота + краска). |
| **Снег** | Краска только для снега (та же маска, что в игре). `Shift` = удаляет её и восстанавливает исходное. |

## 📐 Формы

[Overview](Overview) · Переключение клавишей `.`. Все поддерживают отмену.

| Форма | Разметка | Применение |
|-------|---------|----------|
| **Круг** | Один клик (центр кисти) | Обычная лепка |
| **Квадрат** | Один клик (центр) | Платформы, фундаменты |
| **Линия** | 2 клика (A → B) | Дорожки, стены, тропы. Полуширина = радиус. |
| **Прямоугольник** | 2 клика (противоположные углы) | Фундаменты, фермы, платформы. Мягкие края. |
| **Полигон** | Клик по каждой вершине, двойной клик закрывает (3+ вершин) | Сложные формы, пользовательские области |

- Некруглые формы показывают **только отмеченный контур** (без круглых колец).
- Мягкость влияет на смешивание краёв у всех форм.

## ⚙️ Режимы затухания (Поднять/Опустить)

[Overview](Overview) · Настройка в НАСТРОЙКАХ → "Затухание Raise/Lower":

| Режим | Поведение |
|------|----------|
| **Остроконечный** | Центральный пик. Управляется слайдером "Сила затухания" (1–5). |
| **Плоский** | Равномерный диск — одинаковый вес по всему радиусу. |
| **Плавный** | Косинусный колокол — плавный переход, без резкого края. |
| **Линейный** | Прямое сужение от центра к краю. |

## 🧱 Штампы (Копировать/Вставить)

[Overview](Overview) · Мощная функция для копирования структур местности.

### Выделение прямоугольником (рекомендуется)

[Overview](Overview) · 1. Установите форму `Rectangle` (клавиша `.`).
2. Нажмите Применить (`Mouse1`) **один раз**, чтобы отметить угол **A** (это **не** вносит правок).
3. Наведитесь на угол **B** (просто переместите камеру).
4. Нажмите `Ctrl+Shift+C` → копирует ровно этот прямоугольник, **обрезанный по выделению** (не захватывает целые плитки по 64 м или нетронутую землю вокруг). Метка угла A расходуется после успешного копирования.

### Рабочий процесс

[Overview](Overview) · 1. **Отметьте область**: используйте любую форму (Круг, Прямоугольник, Линия, Полигон, Пандус) — или выделение прямоугольником выше.
2. **Копировать**: `Ctrl+Shift+C` → "Штамп скопирован: X плиток" (буфер в ОЗУ).
3. **Предпросмотр вставки**: `Ctrl+Shift+V` → призрачный каркас на прицеле.
   - `Q`/`E` = поворот ±15°
   - `Alt`+Колесо = непрерывный поворот
   - `Shift`+Колесо = масштаб 0.25×–4×
   - `Esc` = отмена
4. **Подтвердить**: клик (`Mouse1`) → применяется как **один шаг отмены**.

> Штампы выделения записывают **только внутри скопированной области**; местность снаружи остаётся нетронутой.

### История
- До **10 штампов** в ОЗУ (сначала самые новые).
- Клавиши `Следующий штамп` / `Предыдущий штамп` (переназначаемые) перебирают их.
- Вспышка: "История штампов: Copy: 3 плитки [2/5]"

### Хранение
- **НАСТРОЙКИ → ШТАМПЫ**:
  - Сохранить текущий штамп на диск (`.stamp` в `BepInEx/config/TerrainForge/stamps/`, макс. 12).
  - Загрузить штамп в буфер обмена.
  - Список/удаление сохранённых штампов.

### Инструмент штампа
- НАСТРОЙКИ → "Инструмент штампа" (4 варианта):
  - `Same as brush` (по умолчанию) — использует тот же инструмент, что и кисть
  - `Any` — без требований
  - `Pickaxe` — требуется экипированная кирка
  - `TerrainForge Rod` — требуется жезл мода
- HUD показывает `STAMP READY [2/5]`, когда инструмент экипирован + есть штампы в буфере.
- Без инструмента: `Stamp: tool not equipped`, копирование/вставка заблокированы.

## 💾 Снимки (Резервные копии)

[Overview](Overview) · Полное резервное копирование/восстановление местности.

### Сохранить
1. НАСТРОЙКИ → **СНИМКИ**.
2. Имя (пусто = авто дата/время).
3. **Сохранить** → правленые плитки в `BepInEx/config/TerrainForge/snapshots/<имя>.dat` (макс. 12).

### Загрузить
1. Выберите снимок.
2. **Загрузить** → восстанавливает плитки с правами владения, **1 шаг отмены**.
3. Незагруженные плитки корректно предупреждают — импортируйте рядом с исходным местоположением.

### Возможности
- Версионированный бинарный формат (`.dat`).
- Восстанавливает высоту + сглаживание + краску + права владения.
- Импорт можно отменить (`Ctrl+Z` откатывает импорт).
- Незагруженные плитки корректно предупреждают.

## 🌍 Мультиплеер

[Overview](Overview) · ### Требования
- **Мод на клиенте И сервере** для правок больше ±8 м и корректной репликации.
- `UnlockDeltaLimit` также на сервере, иначе сервер ограничивает местность.

### Авторитет сервера (синхронизация конфигурации)
Когда сервер использует мод, его секция `Server` имеет приоритет:
- `AllowTerrainEdits` (по умолчанию `true`) — главный переключатель; если `false`, клиенты не могут применять/отменять/повторять.
- `AdminOnlyEdits` (по умолчанию `false`) — редактировать могут только админы/хост.
- `RespectWards` (по умолчанию `true`) — блокирует правки внутри чужих вардов.
- `RadiusCap` / `DeltaCap` (0 = выкл.) — ограничения, применяемые сервером, видны в HUD+предпросмотре.

> Серверы **без** мода игнорируют секцию → клиент работает для тестирования.

### Предотвращение рассинхронизации
- Держите `MaxUpDelta` / `MaxDownDelta` согласованными на сервере + клиентах.
- Большие радиусы могут рассинхронизировать клиентов без мода.

### Vanilla / интеграция
- `BlockVanillaTerrainTools`: false — с экипированным жезлом игнорирует редактирование местности ванильной мотыгой/культиватором. Также есть переключатель в НАСТРОЙКАХ.

### Ввод
Все горячие клавиши переназначаются на вкладке КЛАВИШИ. Основное:
- `ApplyKey` (Mouse1), `RadiusUp/Down` (=/-), `CycleOp/Shape/Paint` (,/.//)
- `UndoKey` (Ctrl+Z), `RedoKey` (Ctrl+Y), `EyedropKey` (G), `RampModeKey` (H)
- `RadialKey` (Q), `AdjustModeKey` (V), `GiveToolKey` (F8), `RebindMenuKey` (F5)
- **Прямые клавиши операций** (9, без значения по умолчанию): OpFlatten/Raise/Lower/Smooth/Paint/Restore/Ramp/Shore/Snow
- `CycleProfileKey`, `CycleStampKey`, `CycleStampBackKey`
- `RequiredTool`: Any / Pickaxe / TerrainForgeTool (по умолчанию)
- `AutoGiveTool`: true (выдаёт жезл при входе)

### Штампы
- `StampToolMode`: Same as Brush / Any / Pickaxe / TerrainForgeTool (по умолчанию Same as Brush)

### Предпросмотр
- `ShowPreview`: true, `ShowGuides`: true (направляющие досягаемости, оттенок уклона, кольцо уровня)

### История
- `UndoDepth`: 50 (0–500, 0 отключает историю)

### Сервер (авторитетно через синхронизацию конфигурации)
- `AllowTerrainEdits`: true (главный переключатель)
- `AdminOnlyEdits`: false (только админы)
- `RespectWards`: true (блокирует чужие варды)
- `RadiusCap` / `DeltaCap`: 0 (выкл.) — ограничения, применяемые сервером

### Производительность
- `TilesPerFrame`: 4 (1–32 плитки/кадр)

## 🐛 Решение проблем

[Overview](Overview) · | Проблема | Решение |
|-------|----------|
| **Меню не появляется / невидимый курсор** | Закройте игру. Удалите `%APPDATA%\Thunderstore Mod Manager\DataFolder\Valheim\profiles\ВашПрофиль\BepInEx\plugins\TerrainForge\` и `%APPDATA%\Thunderstore Mod Manager\PackageCache\`. Перезапустите TMM, проверьте обновления. |
| **Обновление не отображается в TMM** | TMM → Settings → "Refresh mod list" (Ctrl+R). Закройте/откройте TMM. Проверьте правильный профиль. |
| **Конфликт версий в Thunderstore** | Поднимите версию (0.3.3 → 0.3.4) в `.csproj`, `Plugin.cs`, `manifest.json`. Пересоберите + перезагрузите. |
| **Копирование/вставка штампа ничего не делает** | HUD: `STAMP READY [X/Y]` = готово. Если "инструмент не экипирован", экипируйте инструмент (НАСТРОЙКИ → Инструмент штампа). |
| **Предпросмотр невидим под водой** | Исправлено в 0.3.2 — предпросмотр плавает на поверхности. Обновитесь. |
| **Круги на Линии/Прямоугольнике/Полигоне** | Исправлено в 0.3.2 — показывается только отмеченный контур. Обновитесь. |
| **Радиальное колесо не работает** | Исправлено в 0.3.2 (`ZInput.GetMouseScrollWheel()`) и 0.3.4 (выделение больше не стирается при центрированном курсоре). Обновитесь. |
| **Конфигурация не сохраняется** | Закройте меню (F5) для автосохранения. Или отредактируйте `BepInEx/config/com.terrainforge.valheim.cfg` напрямую. |
| **Рассинхронизация в мультиплеере** | Мод на клиенте+сервере. `UnlockDeltaLimit` на обоих. Одинаковые `MaxUpDelta`/`MaxDownDelta`. |
| **Сборка не удаётся** | Проверьте пути `ValheimDir`, `BepInExCoreDir`, `JotunnDir` в `.csproj` или через CLI. Требуется .NET SDK 8+. |
| **Компиляция / упаковка** | `dotnet build -c Release` (DLL в `build/`), `-p:Deploy=true` (устанавливает в профиль) или `-p:Package=true` (zip в `build/`). |
